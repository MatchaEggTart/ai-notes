# 第 1 课：data 是海拔，grad 是坡度

**这一课只解决一件事**：分清「函数值」和「该点的斜率」。
读 `engine.py` 之前必须先分清，否则 `self.data` 和 `self.grad` 会在脑子里糊成一个东西。

## 起点：你的答案

问 `f(x) = x²` 在 `x = 3` 处的斜率，你答 `9`。

`9` 没错，但它是 `f(3)` —— 山在 `x = 3` 处的**海拔**。斜率问的是**坡度**：站在那儿，
再往前走一小步，海拔涨得多快。答案是 `6`。

一个人身上有两个数，不是一个：

| x | f(x) = x²（海拔） | 斜率（坡度） |
| --- | --- | --- |
| 0 | 0 | 0 |
| 1 | 1 | 2 |
| 2 | 4 | 4 |
| **3** | **9** | **6** |
| 4 | 16 | 8 |

`x = 3` 那行：海拔 9，坡度 6。**没有矛盾，是两个不同的量。**

坡度为什么是 `2x`？看 `x = 2 → 3`：海拔从 4 涨到 9，涨了 5；`x = 3 → 4`：从 9 涨到 16，
涨了 7。涨速在**加快** —— 在 `x = 3` 这一点，瞬时涨速是 6。规则 `(x²)' = 2x` 就是这么观察出来的。

## 落到 engine.py

打开 `code/micrograd/engine.py`，看 `Value.__init__` 的前四行：

```python
def __init__(self, data, _children=(), _op=''):
    self.data = data
    self.grad = 0
```

- `self.data` = **海拔**：前向算出来的值
- `self.grad` = **坡度**：反向算出来的导数，初始化为 0（还没开始爬，坡度未知）

`backward()` 干的事，就是把每个节点的坡度从输出一路填回去。所以一个 `Value` 里
同时装两套数，`data` 走正向、`grad` 走反向 —— 你现在已经知道为什么要分成两个字段了。
