# ai-notes

AI 相关的学习笔记与资料整理。

## 目录约定

| 路径 | 内容 |
| --- | --- |
| `docs/` | 成篇的笔记、教程整理、路线文档 |
| `python/` | Python 学习笔记与练习 |
| `install/` | 环境 / 服务安装脚本 |
| `papers/` | 论文阅读笔记（计划） |
| `code/` | 练习代码、demo、notebook（计划） |
| `assets/` | 图片等附件（计划） |

## 写作约定

- **自己手写**的笔记用 Org（`.org`），文件名用序号 + 主题，如 `python/02_Variable.org`
- **AI 生成 / 整理**的文档用 Markdown（`.md`），文件名小写加连字符，如 `docs/ai-roadmap.md`
- 每个主题一份索引笔记，链接到相关文件
- 练习代码尽量可运行，并在头部注明依赖
