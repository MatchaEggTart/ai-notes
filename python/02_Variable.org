* 变量

** 程序

*** 概念

程序是数据和指令的有序集合；写程序就是用它们让计算机做我们想做的事。

** 变量和类型

*** 概念

变量是**绑在对象上的名字**，不是「一块用来保存数据的内存空间」。
类型属于**对象**：`45` 是 int 对象，`"hello"` 是 str 对象，名字本身没有类型。
（模型和实测证据见下面 [[*变量的使用][变量的使用]] 的卡点。）

计算机能处理的数据有很多种：数值、文本、图像、音频、视频……

*** 整型(int)

Python 的 int 是**任意精度**的（Java 的 int 固定 32 位、long 64 位）。
支持二进制 `0b100`、八进制 `0o100`、十进制 `100`、十六进制 `0x100` 四种字面量。

*** 浮点型(float)

小数。支持数学写法（`123.456`）和科学计数法（`1.23456e2` = 1.23456 × 10²）。
它是二进制近似值，不精确（见卡点）。

*** 字符串型(str)

用单引号或双引号包裹的任意文本，`'hello'` 和 `"hello"` 完全等价。

*** 布尔型(bool)

只有 `True` / `False`，表示真/假、是/否。它其实是 int 的子类。

*** 用法

variable_type.py

#+begin_src python
# 四种进制
print("0b100 =", 0b100)   # 4
print("0o100 =", 0o100)   # 64
print("0x100 =", 0x100)   # 256
print("2**100 =", 2 ** 100)

# 浮点
print(123.456)
print(1.23456e2)

# 字符串 / 布尔
print("hello", 'hello')
print(True)

# 查类型
for v in (45, 123.456, "hello", True):
    print(v, "->", type(v).__name__)
#+end_src

*** 卡点

**** 「任意大小的整数」是真的

Java 的 int 固定 32 位、long 64 位；Python 的 int 没有上限。实测：
`2 ** 100` → `1267650600228229401496703205376`；`2 ** 1000` 也能算（302 位）。
（注：`sys.maxsize` 不是 int 的上限，那是容器长度/索引的上限，别搞混。）

**** 浮点数不精确

实测 `0.1 + 0.2` → `0.30000000000000004`，`0.1 + 0.2 == 0.3` → `False`。
小数在二进制里是近似的（Java 的 double 同样如此）。
放过误差用差值阈值；要精确十进制用 `decimal.Decimal`。

**** True 其实是 1

实测 `isinstance(True, int)` → `True`，`True + True` → `2`。
bool 是 int 的子类，`True` 能当数字用——别指望它帮你拦住类型错误。

** 变量命名规则

*** 规则

(1) 由字母、数字、下划线构成，数字不能开头
(2) 大小写敏感
(3) 不要跟关键字/保留字重名

*** 惯例

(1) 小写字母 + 下划线连接，如 `my_var`
(2) 单下划线开头 `_x`：约定「内部使用」
(3) 双下划线开头 `__x`：**名字改写**，不是「私有」

*** 卡点

**** Python 没有 private

教程说「`__x` 是私有变量」→ 不准确。实测：

#+begin_src python
class A:
    def __init__(self):
        self.__x = 1
        self._y = 2

print(A().__dict__)      # {'_A__x': 1, '_y': 2}
#+end_src

`__x` 被**改写成 `_A__x`**（name mangling），从外面 `a._A__x` 照样能读。
它的作用是「防止子类不小心覆盖」，不是「禁止访问」。`_x` 更弱，纯约定，解释器不管。

** 变量的使用

*** 概念

变量不是「有类型的盒子」，而是**绑在对象上的名字**。类型属于对象，不属于名字。
（C 里 `int a` 是一块有类型的槽；Python 里 `a` 只是一个名字，`a = ...` 是「重新绑定」。）

*** 用法

variable_use.py

#+begin_src python
a = 45        # 定义变量 a
b = 12        # 定义变量 b
print(a, b)   # 45 12
print(a + b)  # 57
print(a - b)  # 33
print(a * b)  # 540
print(a / b)  # 3.75   ← 见下面卡点
#+end_src

*** 卡点

**** 45 / 12 不是 3

我以为 `45 / 12` 是 `3`（Java 的整数除法）→ 其实是 `3.75`。
Python 的 `/` 永远返回 float；要整除用 `//`（实测 `45 // 12 = 3`）。

**** 「指针没改」正好说反了

我以为「a 装过整数就不能再装别的，反正指针没改」→ 其实名字会**重新绑定**到新对象，
连指向谁都换了。实测：

#+begin_src python
a = 45
print(type(a).__name__, id(a))   # int 139850826940048
a = "hello"
print(type(a).__name__, id(a))   # str 139850816263328
#+end_src

「有类型的盒子」是 C 的模型，在 Python 里会坑人。实测**别名**：

#+begin_src python
a = [1, 2]
b = a
b.append(3)
print(a, a is b)     # [1, 2, 3] True
#+end_src

a、b 是同一个对象的两个名字，改 b 就是改 a；C 里 `int a = 1, b = a; b = 2;` 不会动 a。

Java 对照：`int a = 45; a = 100;` 合法（类型没变）；`int a = 45; a = "hello";` 编译错。
Python 根本没有「声明类型」这回事，所以永远合法。

**** f-string 不叫 fprint，也不是新东西

我以为那是「fprint」，还是「很新的 Python 才能用」→ 其实是 **f-string**（格式化字符串字面量），
Python **3.6**（2016，PEP 498）就有，到今天十年了。而且文件里其实是**三代**写法：

#+begin_src python
print("b %s type is %s" % (b, type(b)))       # 第一代：% ，抄 C 的 printf
print("b {} type is {}".format(b, type(b)))   # 第二代：str.format()
print(f"b {b} type is {type(b)}")             # 第三代：f-string
#+end_src

三者输出一样（实测）。新代码统一用 f-string。
（学过 C 的话，`%d / %s` 就是熟悉的 printf，这是个现成的桥。）

**** type() ≠ typeof()

我以为 `type()` 相当于 Java 的 `typeof()` → Java **没有** `typeof()`，那是 JavaScript 的运算符。
Python 的 `type(a)` 返回对象的类，对应的是 Java 的 `a.getClass()`。别跟 JS 混。
